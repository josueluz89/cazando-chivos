# Cazando Chivos

Cartelera web de conciertos de rock en vivo ("chivos") en Heredia y el Gran Área Metropolitana, Costa Rica.

Sitio estático: abrir `index.html` en el navegador o publicarlo con GitHub Pages.

## Estructura

- `index.html` — la app completa (datos incluidos)
- `assets/` — logo y flyers de los eventos

## Actualizar eventos

Los datos de bares y eventos están incluidos en el `index.html` (arreglo de eventos con banda, bar, fecha, hora, cover, flyer y dirección).
